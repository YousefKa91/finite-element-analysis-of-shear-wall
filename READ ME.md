# FEM (ANSYS) — 2D Linear Elastic Study + Analytical Comparison

This repository contains a course FEM project report (PDF) for a **2D linear-elastic analysis in ANSYS** under a **plane stress** assumption, applied to a **shear wall Analysis**.

## Contents
- `report.pdf` — Full write-up (problem definition, modeling choices, results, basic verification, FEM vs analytical comparison)

## What we did (high level)
- Defined geometry (shear wall with openings), material model, loading, and boundary conditions 
- Built a 2D FE model in **ANSYS** and generated meshes (including refinement/consistency checks) 
- Post-processed displacements and stress fields to identify critical regions
- Compared FE results with a simplified analytical cantilever-style estimate (see report for assumptions)
- Performed basic verification checks (e.g., equilibrium and result consistency)

This is a 2014 university FEM assignment completed by Yousef Karevan and Ali Khangholi. In 2026 I made minor grammar/formatting corrections and uploaded it for portfolio purposes.
This is a technical course study intended to demonstrate FEM fundamentals and verification practices rather than a publication-ready analysis.
